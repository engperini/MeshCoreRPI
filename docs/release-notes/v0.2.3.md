## MeshCoreRPI v0.2.3

### Fixed
- Repeater: radio params set in `/etc/raspberrypimc/repeater.env` are now also stored in the repeater's prefs, so the web dashboard and `get radio` show the frequency the radio really uses (before, they showed the old 915 MHz default).

### Since v0.2.1
- USB MeshStick: fresh installs enable the TCXO and DIO2 RF switch; clear error if the radio oscillator fails to start.
- Message terminal: RemoteTerm on the Pi, optional full-screen kiosk (`RaspberryPiMC/terminal/setup-terminal.sh`).

Install: `curl -fsSL https://raw.githubusercontent.com/engperini/MeshCoreRPI/main/install.sh | sudo bash` (repeater: `| sudo bash -s -- repeater`)
