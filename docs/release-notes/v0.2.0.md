## MeshCoreRPI v0.2.0: USB MeshStick support

Run MeshCore natively on a Raspberry Pi with a **USB LoRa stick**: no HAT, no flashing.

### Install

```bash
curl -fsSL https://raw.githubusercontent.com/engperini/MeshCoreRPI/main/install.sh | sudo bash
```

Or download a `.deb` below (64-bit Raspberry Pi OS, `arm64`) and run `sudo apt install ./raspberrypimc-native-companion_*.deb`.

### New
- **USB MeshStick (CH341 + SX1262)** driver: `RPI_RADIO_DRIVER=sx1262_ch341`. Pins, TCXO and RF switch preset; clear error if the radio does not answer.
- **Periodic self-advert in minutes** for range tests: `RPI_ADVERT_INTERVAL_MIN`, `RPI_ADVERT_MODE`.
- **One-line installer** and prebuilt `.deb` packages.

### Fixed
- Radio params set from the companion app or loaded from saved prefs were never applied to the chip (it stayed on the startup params). Affects HAT users too: **upgrade recommended**.
- Params forced from the env file are now shown correctly in companion apps.
- Startup info and RX/TX packet logs now show up live in `journalctl`.

Tested on a Raspberry Pi with an Elecrow MeshStick on the MeshCore Brasil network (923.125 MHz, 62.5 kHz, SF8, CR8): adverts, channel messages and acknowledged direct messages both ways.
